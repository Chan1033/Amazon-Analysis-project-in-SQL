
# AMAZON ANALYSIS

Amazon Sales Analysis mini project focuses on analyzing sales data to identify top-selling products, customer purchasing trends, and revenue performance using Excel, SQL, and Power BI. The project helps businesses make data-driven decisions by visualizing sales insights and improving overall performance.


## OBJECTIVES

- Analyze total sales and revenue
- Find top-selling products
- Identify monthly sales trends
- Understand customer purchase patterns

## TOOLS USED

- MY SQL

## DATA SET

- Order Deatails 
- products
- Orders 
- reviews 
- suppliers
